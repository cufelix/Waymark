# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include personal data, credentials, tokens or production URLs in a report.

Use GitHub’s private vulnerability reporting for this repository:

1. Open the repository’s **Security** tab.
2. Choose **Advisories** → **Report a vulnerability**.
3. Include the affected component, impact, reproduction steps and a minimal proof of concept using fake data.

If private vulnerability reporting is not enabled, contact a repository owner privately before sharing details.

## Scope

Useful reports include authentication or cross-seeker access failures, secret exposure, unsafe URL fetching, prompt/tool injection that crosses a trust boundary, incomplete deletion, snapshot path traversal, dependency compromise and leakage of CV/interview content through logs or errors.

## Current status

Waymark is a prototype and has no production-supported release. Security reports are still welcome, but no response-time SLA is currently offered.
